Skribly Agent

Aplikacja desktopowa do uruchamiania kilku agentów AI naraz i pilnowania ich pracy.

Pobierz Skribly Agentagent.skribly.pl: wszystko o Skribly Agent

Opis

Skribly Agent to środowisko desktopowe dla agentów AI. Trzyma projekty, zadania i agentów w jednym oknie, więc nie musisz skakać między terminalami.

Aplikacja czyta ekran każdego agenta i pokazuje, czy pracuje, czeka na Twoją decyzję, czy skończył. Gdy jesteś potrzebny, daje znać, nawet jeśli patrzysz gdzie indziej.

Agenci obok siebie
Claude Code, Codex, Cursor Agent, Gemini CLI i inni w obszarach roboczych, kartach i panelach.
Zadania z trackerów
Jira, Redmine, GitHub, GitLab i Linear na jednej liście. Startujesz zadanie, a agent dostaje gałąź, plik i instrukcję.
Drzewa robocze Git
Każdy agent może pracować we własnej kopii plików, więc agenci sobie nie przeszkadzają.
Potoki
Kroki planowania, budowania i przeglądu, które przekazują pracę między agentami.
Audyty
Sprawdzanie bezpieczeństwa, dostępności i SEO, z wynikami do przekazania agentowi.
Prawdziwy edytor
Monaco z kartami, wyszukiwaniem w plikach, porównaniami obok siebie i grafem historii wszystkich gałęzi.
Commity w Twoim stylu
Propozycje na podstawie historii repozytorium, bez modelu i bez dopisków o AI.
Przeglądarka i Docker
Podgląd w rozmiarach telefonu, tabletu i laptopa oraz widok Twoich kontenerów.
CLI i MCP
Agenci mogą uruchamiać innych agentów, wysyłać im instrukcje, czekać na nich i ich czytać.
Ustawienia dostępności
Rozmiar tekstu, wysoki kontrast, ograniczony ruch, podkreślone linki i wyraźny wskaźnik fokusu.
Motywy i języki
Tryb dzienny i nocny, motywy edytorów oraz interfejs po polsku i angielsku.

Sposoby pracy

Od zgłoszenia do commita

  1. Otwórz Zadania i wybierz Zacznij z agentem.
  2. Agent czyta TASK.md, proponuje plan i czeka na Twoje OK.
  3. Pracuje etapami i po każdym z nich aktualizuje STATE.md.
  4. Czytasz zmiany w widoku Kod i git.
  5. Zaproponuj pisze wiadomość commita, a Ty robisz commit.

Recenzent obok wykonawcy

Jeden agent uruchamia drugiego przez polecenie skribly, czeka na niego i czyta jego komentarze. Recenzenta możesz obserwować w osobnym panelu i mu odpowiadać.

skribly agent start reviewer --kind claude --prompt "Review the changes from git diff."
skribly agent wait reviewer --until done --timeout 600
skribly agent read reviewer --lines 60 --text

Claude planuje, Codex buduje, Claude sprawdza

Plan, wykonanie i przegląd to jeden z trzech wbudowanych potoków. Recenzent sprawdza git diff i proponuje wiadomość commita.

Trzy audyty naraz

Bezpieczeństwo, dostępność i SEO sprawdzają równolegle trzej agenci, a potem koordynator łączy wyniki w jeden plan poprawek.

Przenieś sesję do innego agenta

Obecny agent zapisuje swój stan do pliku, a nowy startuje obok niego w tym samym drzewie roboczym, bez powtarzania rozmowy.

Od projektu graficznego do kodu

Wyeksportuj paczkę z Claude Design, wybierz agenta i wybierz Wdroż. Agent proponuje plan, a potem buduje z komponentów Twojego projektu.

Bezpieczeństwo

  • Bez konta, bez telemetrii i bez naszego serwera. Agenci korzystają z własnych logowań i kluczy API.
  • Tokeny trackerów są szyfrowane przez systemowy magazyn haseł.
  • API sterowania nasłuchuje tylko na 127.0.0.1 i wymaga tokenu, który zmienia się przy każdym uruchomieniu.
  • Udostępnianie przeglądarki jest domyślnie wyłączone. Gdy je włączysz, dostęp ma każdy program na komputerze, więc włączaj je tylko na czas pracy z agentami.
  • Terminale agentów działają z Twoimi uprawnieniami.
