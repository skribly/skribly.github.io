Tu powstają zadania

Skribly Tracker

Tracker zadań w przeglądarce, z API, dzięki któremu agenci czytają zadania tak samo jak ludzie.

Opis

Skribly Tracker planuje pracę, którą wykonuje reszta Skribly. Ma projekty, zadania, tablice, komentarze i czas pracy, po polsku i angielsku.

REST API korzysta z osobistych tokenów i tych samych ról co ludzie. Skribly Agent oraz umiejętność task z agent-skills używają go jako domyślnego trackera.

Projekty i zadania
Klucze takie jak AGENT-12, typy zadań, priorytety, etykiety, osoby, szacunki czasu i podzadania.
Tablica i lista
Tablica Kanban z przeciąganiem oraz lista z filtrami i wyszukiwaniem.
Praca zespołowa
Komentarze w Markdown, czas pracy, obserwatorzy, załączniki i dziennik aktywności.
Własny workflow
Statusy dla każdego projektu, które możesz zmieniać, układać i dodawać.
Role i tokeny
Role administratora, członka i obserwatora oraz tokeny API tylko do odczytu lub do zapisu.
Webhooki
Podpisane zdarzenia o zadaniach i komentarzach, wysyłane przez kolejkę.
Motyw jasny i ciemny
Podąża za systemem, a na górnym pasku możesz go przełączyć.
Panel dostępności
Rozmiar tekstu, kontrast, czcionki i ruch na każdej stronie.

Sposoby pracy

Zaplanuj i przekaż agentowi

  1. Utwórz zadanie z typem, priorytetem i etykietami.
  2. Przypisz je. Pojawi się w Skribly Agent w sekcji Przypisane do mnie.
  3. Uruchom je z agentem albo wpisz /task AGENT-12 w swoim agencie.
  4. Agent komentuje, zmienia status i zapisuje czas przez API.
  5. Przeglądasz historię zadania, komentarze i czas.

Reaguj na zmiany

Podpisane webhooki wysyłają zdarzenia o zadaniach i komentarzach pod dowolny wybrany adres.

Przeczytaj przewodnik po Skribly Tracker

API

REST API v1 korzysta z osobistych tokenów dostępu z tymi samymi rolami co ludzie. Powstało dla agentów AI tak samo jak dla ludzi i odpowiada jeden do jednego temu, czego Skribly Agent potrzebuje od trackera.

Przeczytaj pełny opis API

Bezpieczeństwo

  • Tokeny API i sekrety webhooków są pokazywane raz i nigdy nie trafiają do logów.
  • Token obserwatora nigdy nie zmienia danych, a tokeny mogą być tylko do odczytu.
  • Webhooki są podpisywane przez HMAC-SHA256.
  • Markdown jest renderowany z escapowaniem surowego HTML, a załączniki zostają na prywatnym dysku.
  • Ponad 240 żądań API na minutę od jednego użytkownika jest odrzucanych.
