Agenci

Skribly Agent uruchamia 13 agentów. Szuka ich w PATH i w typowych miejscach instalacji, a Claude Code znajduje też wtedy, gdy jest zainstalowany tylko jako rozszerzenie edytora. Własne polecenia dodasz w Ustawieniach.

agent-skills instaluje się dla siedmiu agentów. Windsurf jest edytorem, więc Skribly Agent nie uruchamia go w panelu, ale agent-skills go obsługuje.

Gdzie trafiają umiejętności

Każdy agent czyta natywne foldery umiejętności. Sześciu z nich współdzieli .agents/skills, więc jedna kopia wystarcza dla wszystkich, a Claude Code czyta .claude/skills. Niektórzy agenci dostają też krótkie polecenie, które wskazuje umiejętność.

Hostingi Git

Zaloguj się do GitHuba, GitLaba, Bitbucketa, Gitea lub Azure DevOps, a pulpit pokaże Twoją prawdziwą aktywność commitów. Pull requesty idą przez GitHub CLI, a cała reszta pracy z gitem korzysta z Twojego git.

Edytory i motywy

Skribly Agent czyta motywy z VS Code, Cursor, Windsurf i VSCodium albo pobiera je z Open VSX. Potrafi otworzyć plik w każdym z tych edytorów i zainstalować w nich rozszerzenie za Ciebie.

Karta Cursor zarządza regułami projektu w .cursor/rules i serwerami MCP Cursora, a do tego ma akcję Otwórz w Cursor.

MCP, wtyczki i narzędzia przeglądarkowe

  • Serwery MCP Claude Code, Codex, Cursor i Gemini CLI są na jednej liście. Dodaj serwer do kilku agentów naraz albo wyłącz go bez utraty konfiguracji.
  • Wtyczki Claude Code z katalogu Anthropic możesz zainstalować wszędzie, dla projektu albo tylko dla siebie.
  • chrome-devtools-mcp i Playwright MCP mogą sterować przeglądarką aplikacji przez Chrome DevTools Protocol.
  • Paczki z Claude Design mogą trafić do Claude Code, Codex CLI, Cursor Agent, Gemini CLI lub Droid, żeby powstały w Twoim projekcie.
  • skribly mcp to osobny serwer MCP, dzięki któremu agenci mogą uruchamiać i czytać innych agentów.

Narzędzia do audytów i testów

  • OSV.dev dostarcza znane podatności pakietów npm, PyPI i Composer. Wysyłane są tylko nazwy i wersje pakietów.
  • axe-core sprawdza dostępność w Skribly Agent i w umiejętności wcag-audit.
  • PageSpeed Insights albo lokalny Lighthouse mierzą Core Web Vitals w umiejętności pagespeed.
  • Playwright, k6, autocannon, Locust, Schemathesis, Dredd, Hurl i newman służą umiejętnościom testowym.
  • hadolint i actionlint uzupełniają umiejętności docker i ci-setup, jeśli są zainstalowane.

Docker

Skribly Agent używa Twojego polecenia docker, żeby wyświetlać kontenery, wykonywać akcje, czytać logi i pracować z plikami compose. Obserwator w tle zgłasza kontenery, które się wywracają albo restartują w pętli.
