Agents

Skribly Agent runs 13 agents. It looks for them in PATH and in common install locations, and it also finds Claude Code installed only as an editor extension. You can add your own commands in Settings.

agent-skills installs for seven agents. Windsurf is an editor, so Skribly Agent does not run it in a pane, but agent-skills supports it.

Where skills go

Git hosts

Sign in to GitHub, GitLab, Bitbucket, Gitea or Azure DevOps, and the dashboard shows your real commit activity. Pull requests go through GitHub CLI, and all other git work uses your own git.

Editors and themes

Skribly Agent reads themes from VS Code, Cursor, Windsurf and VSCodium, or downloads them from Open VSX. It can open a file in any of these editors, and it can install an extension into them for you.

The Cursor tab manages project rules in .cursor/rules and Cursor's MCP servers, and it has an Open in Cursor action.

MCP, plugins and browser tools

  • MCP servers of Claude Code, Codex, Cursor and Gemini CLI appear in one list. Add a server to several agents at once, or switch one off without losing its configuration.
  • Claude Code plugins from the Anthropic catalogue can be installed everywhere, for a project or just for you.
  • chrome-devtools-mcp and Playwright MCP can control the app's browser over the Chrome DevTools Protocol.
  • Claude Design packages can go to Claude Code, Codex CLI, Cursor Agent, Gemini CLI or Droid to be built in your project.
  • skribly mcp is an MCP server of its own, so agents can start and read other agents.

Audit and test tools

  • OSV.dev provides known vulnerabilities for npm, PyPI and Composer packages. Only package names and versions are sent.
  • axe-core checks accessibility in Skribly Agent and in the wcag-audit skill.
  • PageSpeed Insights or local Lighthouse measure Core Web Vitals in the pagespeed skill.
  • Playwright, k6, autocannon, Locust, Schemathesis, Dredd, Hurl and newman are used by the test skills.
  • hadolint and actionlint add to the docker and ci-setup skills when they are installed.

Docker

Skribly Agent uses your docker command to list containers, run actions, read logs and work with compose files. A watcher in the background reports containers that crash or restart in a loop.
